# m-formBuilder01（フォームビルダー）

- **PHP**: [`m-formBuilder01.php`](m-formBuilder01.php) … `admin_m_form_builder01_description_template()` / `admin_m_form_builder01_field_template()` がそれぞれフラグメントを読み込み、`<template data-target="m-formBuilder01__descriptionTemplate">` / `<template data-target="m-formBuilder01__fieldTemplate">` を出力する。`layouts/admin_components.php` 経由で `require_once`（`admin.js` は `data-target` で参照するため値は変えない）。
- **SCSS**: [`_m-formBuilder01__fieldTemplate.scss`](_m-formBuilder01__fieldTemplate.scss) … `[data-module="m-formBuilder01"]`（`.c-formEditor*` 等のフォームビルダー内スタイル）。説明文エディタの見た目は [`../c-descriptionEditor01/_c-descriptionEditor01.scss`](../c-descriptionEditor01/_c-descriptionEditor01.scss) に移管済み。いずれも [`public_html/assets/scss/_admin-app.scss`](../../../assets/scss/_admin-app.scss) から `@use`。
