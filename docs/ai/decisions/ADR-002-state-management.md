# ADR-002: 状態管理（サーバーサイド中心）

## ステータス

採用

## コンテキスト

フロントエンドのビルドツールや SPA フレームワークを前提にしない。フォーム送信・管理画面は従来型のリクエスト／レスポンスで動かす。

## 決定

- **セッション**: ログイン状態・CSRF トークンなどに使用する（`\Core\Auth` 等）。
- **フラッシュメッセージ**: `flash()` で次リクエスト表示用の一次メッセージを渡す。
- **フォーム状態**: 入力 → 確認は POST とサーバー側のデータ受け渡しで行い、クライアント単体の永続状態には依存しない。

## 結果

- デプロイが単純で、レンタルサーバー制約に合う。
- リアルタイム性が必要になった場合は、この ADR を更新して別手段（SSE / 小さな JS モジュール等）を検討する。
