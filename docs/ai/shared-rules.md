# 共有ルール（補足）

本書は [`AGENTS.md`](../../AGENTS.md) の補足である。矛盾がある場合は **AGENTS.md を優先**する。

## コードスタイル

- PHP: 既存ファイルの名前空間・インデント・配列記法に合わせる。
- ビュー: エスケープは `e()`、CSRF は `\Core\Csrf::field()` 等、既存ヘルパを踏襲する。
- フロント資産: `public_html/assets/scss/` で編集し、必要に応じて `npm run build:css` で CSS を再生成する。

## ドキュメント

- 仕様のたたき台や API メモは [`docs/specs/`](../specs/) に置く（ファイル名は英語または日付プレフィックスでよい）。
- 「なぜそうしたか」は ADR に残す（[`decisions/`](decisions/)）。

## テスト・確認

- 大きな変更後は、公開フォーム（入力→確認→送信）と管理画面の該当画面を目視確認する旨を changelog や PR に書いてよい。
