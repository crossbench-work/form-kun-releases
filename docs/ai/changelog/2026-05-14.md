# Changelog 2026-05-14

## スタイル・マークアップ

- フォーム項目エディタの `m-requiredCheck01` は、ラベル全体の背景・枠線・余白を削除し、必須チェックのアイコンだけが見える表示に調整した。
- `m-formBuilder01` 内の `.c-formEditor__item > .wrapper > .block.is-body` に `padding-top: 16px` を追加し、本文内余白を上下左右で揃えた。
- バリデーション未選択で入力チェック UI が非活性のときは、ラッパー全体の不透明度と disabled 入力色をさらに薄くして状態差を見やすくした。
- フォーム項目に `text_multi`（1行テキスト（複数入力））型を追加し、管理画面では表示設定に「表示名 + プレースホルダ」の行を 1 件だけ初期表示、`入力欄を追加する` ボタンで項目を増やせるようにした。
- `text_multi` は公開フォーム・確認画面・管理画面送信一覧/詳細・メール本文でも複数入力として整形表示し、送信値は JSON 形式で保持できるようにした。
- 公開フォームの `text_multi` は、複数入力欄が画面幅に応じて横並びになるグリッド表示へ調整した。
- `form_fields.type` ENUM に `text_multi` を追加する schema / migration / SchemaPatch を更新した。
- `Validator::decodeOptions()` は配列要素がスカラー以外でも安全に無視するようにし、`text_multi` の設定読込時に `Array to string conversion` 警告が出ないようにした。
- 管理画面の型選択から `1行テキスト` と `1行テキスト（2入力）` を外し、単一行入力は `1行テキスト（複数入力）` に統合した。
- 既存の `text` / `text_pair` フィールドは読み込み時に `text_multi` へ正規化し、旧データでも表示・確認・送信一覧・メール本文が崩れないようにした。
- `text_multi` の入力欄は 1 項目のときだけ表示名を省略可能にし、旧 `1行テキスト` と同様の 1 入力運用を継続できるようにした。
- `text_multi` の表示名を `1行テキスト` に変更し、管理画面・公開画面ともに単一行入力の名称を統一した。
- フォーム末尾に固定で入っていた `規約への同意` 項目は自動追加と専用表示を廃止し、既存データに残っている同項目もフォーム編集・公開表示・保存処理から除外するようにした。
- フォーム編集画面から `スパム対策（簡易計算CAPTCHA）を有効にする` 設定を削除し、管理画面から保存したフォームは CAPTCHA を常時有効の扱いに整理した。
- 説明文ブロックの入力欄を `c-htmlInputEditor01` としてモジュール化し、通常はテキスト入力、チェック時のみ HTML 入力として扱える切替 UI に変更した。
- 説明文ブロックは `is_html` フラグを保存できるようにし、テキスト入力時は改行を保ったまま表示、HTML 入力時だけ許可タグをサニタイズして描画するようにした。
- `HTMLで入力する` チェックは入力エリアの左下へ移動し、HTML 入力時の補助文 `HTML を直接入力できます。一部のタグと属性だけが保存されます。` は非表示にした。
- `HTMLで入力する` チェックの文字サイズを 12px に調整した。
- 項目設定の `備考` も `c-htmlInputEditor01` を使う構成へ変更し、通常はテキスト、チェック時のみ HTML 入力として保存・表示できるようにした。
- 項目設定内の型プルダウンは廃止し、`＋ 項目を追加` 押下時にモーダルで追加する型を選んでから項目を生成する方式へ変更した。
- 追加済み項目の型は `c-formEditor__item` 内で固定表示に切り替え、後から変更できない UI に整理した。
- 型選択モーダルは `hidden` 属性を優先するようにし、フォーム編集画面を開いた直後にモーダルが表示されたままになる不具合を修正した。
- `c-formEditor__field` 内に残っていた型の表示エリアは削除し、項目内部では型を見せず hidden 値だけ保持する構成に整理した。
- 入力設定の必須チェックは `必須` の文言が見える従来の見た目へ戻し、見出し文言は `バリデーション` から `入力チェック` に変更した。
- `c-formEditorSummary01` の入力チェック表示は文言ラベルではなくチェックマークアイコン付きの表示へ変更した。
- `c-formEditorSummary01` は任意項目のとき、`必須` ラベルと入力チェック表示の両方を非表示にするようにした。
- `c-formEditorSummary01` は入力チェックのプルダウンが `なし` のときも `.regex` を非表示にし、実際に入力チェックが設定されている場合だけ表示するようにした。
- `c-formEditorSummary01 > .regex` は `hidden` 属性付きのとき `display: none` を明示し、`なし` 選択時に見えてしまう表示崩れを修正した。
- `.c-formEditorSummary01 > .regex[hidden]` の SCSS 反映漏れを補い、`なし` 選択時に `<p class="regex" ... hidden>` が確実に非表示になるよう再修正した。
- 入力設定の `必須` チェックは、チェックボックスのアイコンと `必須` 文言が縦並びになるようラベルレイアウトを調整した。
- `c-formBlock01 .label.is-choice` の横並び指定が `m-requiredCheck01` に勝っていたため、`m-requiredCheck01 .label.is-choice` を明示して必須チェックのアイコンと文言が確実に縦並びになるよう再修正した。
- `c-formBlock01` 配下の汎用 `label` / `.label` スタイル上書きに対応するため、`m-requiredCheck01` 側で `label` / `.label` / `.label.is-choice` をまとめて上書きし、必須チェックの縦並びがモジュール内だけで完結するよう再整理した。
- ラジオボタン・チェックボックス・プルダウンの `入力チェック` にも `なし` を選べるようにし、ラジオボタンとプルダウンは `なし` のみ、チェックボックスは `なし` / `カスタム` / `選択数を設定する` を選べるように整理した。
- 管理画面のパネル外枠 `c-panel01` は廃止し、`c-formBlock01` 自体が白背景・枠線・角丸・余白を持つ構成へ統合した。フォーム編集・一覧・送信履歴・ユーザー管理・ダッシュボードのテンプレートと HTML マークアップ規約も新構造に揃えた。
- 入力画面・確認画面・完了画面ごとに個別タイトルを設定できるようにし、基本設定のタイトルは公開フォームへ直接出力しない構成へ変更した。管理画面から `表示する` チェックを削除し、既存フォームは入力画面タイトルに基本設定タイトル、確認/完了画面タイトルに従来の見出し文言を自動補完する migration / SchemaPatch を追加した。
- 入力画面・確認画面・完了画面のタイトルにはそれぞれ `表示する` チェックを追加し、公開側でも各画面ごとに見出しの表示/非表示を切り替えられるようにした。既存フォームは新しい表示フラグを有効で補完する migration / SchemaPatch を追加した。
- フォーム新規作成時は、`スラッグ（URL用）` に UUID を初期値として自動入力するようにした。
- 管理者通知メールの `使用可能な変数` はクリックでコピーできるタグ表示に変更した。
- 送信者への自動返信メールの最下部にも、同じ `使用可能な変数` のコピー用タグを追加した。
- `使用可能な変数` は `c-inputSet01` として切り出し、件名・表示設定と並列の入力セット構造に揃えた。
- スパム対策（CAPTCHA とハニーポット）を公開フォーム・送信処理・保存項目から削除し、関連ファイルと `captcha_enabled` の schema 定義も整理した。
- 管理者通知メールは送信先を 1 件ずつ送るようにし、複数宛先や管理者通知の送信経路でも配信されるよう Mailer を修正した。
- 自動返信メールの `送信先のフィールドキー（メール型項目）` は、`送り元のメールアドレス` 表記へ変更した。
- 自動返信メールは送信先のフィールドキー指定をやめ、フォーム内のメール項目から送信先を自動判定する方式へ変更した。設定項目は実際の `送り元のメールアドレス` 入力として使い、指定時は自動返信メールの `From` / `Reply-To` に反映するようにした。
- 自動返信メールは上記の自動判定仕様を取りやめ、`送信先のフィールドキー（メール型項目）` で指定したメール型項目の値を宛先に使う元の方式へ戻した。管理画面の入力欄もフィールドキー指定の案内へ戻した。
- メール送信に SMTP 設定を追加し、`mail.transport = smtp` または `mail.smtp.enabled = true` のときは `Mailer` が SMTP サーバーへ直接接続して管理者通知・自動返信・管理画面のメール送信を行えるようにした。`config.php` に既定値、`config.local.example.php` に Mailpit / MailHog 向けのローカル設定例も追加した。
- 管理画面に `通知設定` を追加し、差出人情報と SMTP のホスト・ポート・暗号化・認証・証明書検証を UI から保存できるようにした。設定は `app_settings` テーブルへ保存し、起動時に `config.php` / `config.local.php` の上から読み込んでメール送信へ反映する。
- 通知設定は全体設定ではなく各フォームの `通知` タブ内へ移し、フォームごとに差出人情報と SMTP 設定を保存・利用できるようにした。管理者通知メールと自動返信メールは、そのフォームに保存された通知設定を優先して送信する。
- 説明文エディタは `c-formEditor__item` に寄せたカード UI へ変更し、各ブロックをアコーディオン開閉・ドラッグ並び替え・ヘッダー内の目アイコンによる表示切替・ラベル表示・削除に対応させた。説明文ブロックには管理画面用ラベルを追加保存できるようにし、本文入力や表示位置も `c-inputSet01` 構造へ揃えた。
- 説明文エディタ全体は各画面設定の `c-inputSet01` 内へ移し、セット見出しとして `説明文` を表示する構成に揃えた。
- 説明文エディタの追加ボタンは `＋ 項目を追加` 表記の共通ボタンに揃え、`m-formBuilder01__add` と同じターゲット属性でも項目追加と干渉しないよう JavaScript の取得スコープを調整した。
- フォーム項目エディタのヘッダーにも説明文ブロックと同じ目アイコンを追加し、項目ごとの表示/非表示を切り替えられるようにした。`form_fields.visible` を追加して保存・プレビュー・公開フォームへ反映し、送信履歴の管理画面では非表示項目も引き続き参照できるようにした。
- `c-descriptionEditorSummary01` に表示位置の情報も表示し、`先頭` / `末尾` の選択変更がヘッダー要約へ即時反映されるようにした。
- `c-descriptionEditorSummary01` と `c-formEditorSummary01` の表示アイコンは、サマリー先頭ではなく右端の削除アイコン直前へ移し、ヘッダー内の操作アイコン位置を統一した。
- `c-formEditor__itemHeader` の上下移動ボタンは削除し、フォーム項目の並び替え操作はドラッグハンドルのみに統一した。
- アプリの表示名を `ふぉーむくん` に変更し、管理画面・公開レイアウト・メール差出人名・パスワード再設定メール件名・README の名称表記を揃えた。
