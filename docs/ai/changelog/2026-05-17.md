# Changelog 2026-05-17

## 管理画面 UI（c-formEditorItem01）

- `public_html/app/components/c-formEditorItem01/` を追加し、`.c-formEditor__item` の共通シェルを `admin_c_form_editor_item01_open` / `admin_c_form_editor_item01_close` へ切り出した。
- フォーム編集の既存項目（`_field_editor.php`）、説明文ブロック（`edit.php`）、追加用テンプレート（`m-formBuilder01_description_template.php` / `m-formBuilder01_field_template.php`）を新ヘルパー呼び出しへ置換した。
- `.c-formEditor__item` の外枠・折りたたみ・ソートプレースホルダの SCSS を `public_html/app/components/c-formEditorItem01/_c-formEditorItem01.scss` に移し、`public_html/assets/scss/_admin-app.scss` から `@use` で読み込むようにした。
- `public_html/app/views/layouts/admin_components.php` に `c-formEditorItem01.php` の読み込みを追加した。

## フォーム編集画面（DOM 閉じタグ整合）

- 原因: タブ partial・フローティングバー・説明文マークアップが `*_open()` / `*_close()` のペアを守らず、ファイル横断の手書き `</div>` 本数で表示を維持していた。
- `p-formEdit01_floating_actions.php` で `admin_m_btn01_close()` を追加し、フローティングバーを自己完結させた。
- `edit.php` から `$renderDescriptionEditor` クロージャを削除し、`c-descriptionEditor01` コンポーネント（`admin_c_description_editor01`）へ移した。各 `m-inputSet01` / `m-btn01` を close するよう修正。
- `_form_edit_tabs_close.php` を追加し、`c-formEditTabs01` の終了を mail タブ直後に明示。mail 末尾のタブシェル用余分な `</div>` を除去。
- `_form_edit_tab_contents_{basic,fields,confirm,thanks,mail}.php` を `admin_c_form_block01_close()` / `admin_m_input_set01_close()` で各ファイル内完結するよう整理。

## 管理画面 UI（c-btnSet01）

- `public_html/app/components/c-btnSet01/` を追加し、`admin_c_btn_set01_open` / `admin_c_btn_set01_close` を `c-btnSet01.php` に定義した。
- `public_html/app/components/c-btnSet01/_c-btnSet01.scss` に `c-btnSet01` のレイアウトスタイルを移し、`public_html/assets/scss/_admin-app.scss` から `@use` で読み込むようにした（既存の `[data-module="c-btnSet01"]` 定義は `_admin-app.scss` から削除）。
- `public_html/app/views/layouts/admin_components.php` に `c-btnSet01.php` の読み込みを追加した。
- `public_html/app/views/admin/forms/edit.php` の保存/キャンセルボタン枠を `admin_c_btn_set01_open` / `admin_c_btn_set01_close` に置き換えた。
