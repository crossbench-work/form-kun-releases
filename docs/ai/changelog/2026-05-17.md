- `edit.php` から `$renderDescriptionEditor` クロージャを削除し、`c-descriptionEditor01` コンポーネント（`admin_c_description_editor01`）へ移した。各 `m-inputSet01` / `m-btn01` を close するよう修正。
- `_form_edit_tabs_close.php` を追加し、`c-formEditTabs01` の終了を mail タブ直後に明示。mail 末尾のタブシェル用余分な `</div>` を除去。
- `_form_edit_tab_contents_{basic,fields,confirm,thanks,mail}.php` を `admin_c_form_block01_close()` / `admin_m_input_set01_close()` で各ファイル内完結するよう整理。
