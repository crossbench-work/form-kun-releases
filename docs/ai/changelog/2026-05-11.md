## 公開フォーム

- フォーム説明文（`.p-formShow01 .block.is-lead`）の背景色と内側余白を削除し、表示を軽くした。
- フォーム説明文（`.p-formShow01 .block.is-lead`）の罫線と角丸を外し、入力欄プレースホルダーの色を薄く調整した。
- 基本設定に「公開フォームでタイトルを表示する」「公開フォームで説明文を表示する」を追加し、公開フォーム側で個別に非表示化できるようにした。
- 新規フォーム作成時の初期項目を空にし、未追加のまま再表示された場合も自動で「お名前」を補完しないようにした。
- 項目型に「1行テキスト（2入力）」を追加し、管理画面で2つの入力欄名を個別設定できるようにした。
- 「1行テキスト（2入力）」で左右それぞれに別のプレースホルダを設定・表示できるようにした。
- 公開フォームのヘッダーとフッターを既定で非表示にした。
- ラジオボタン等の選択肢を「＋ 選択肢を追加」で増やせるようにし、管理画面上で並び替えできるようにした。
- 項目操作の「上へ」「下へ」「削除」を `.fb-field-header` の右側へ移動した。
- ラジオボタンとチェックボックスではプレースホルダ設定を表示・保存しないようにした。
- プルダウンでもプレースホルダ設定を表示・保存しないようにした。
- ラジオボタン・チェックボックス・プルダウンでは最大文字数設定を表示・保存しないようにした。
- 入力チェックは「必須にする」をオンにした項目だけ表示し、オフ時は保存しないようにした。
- 項目ヘッダーのサマリーに必須/任意と入力チェックを表示し、必須設定と入力チェック設定を同じ塊にまとめた。
- 項目ヘッダーの「上へ」「下へ」ボタンを矢印だけの表示にした。
- 項目ヘッダーの移動ボタンと削除ボタンを `fb-drag-handle` の右側へ移動した。
- 項目ヘッダーの削除ボタンをゴミ箱アイコン表示にした。
- 項目ヘッダーの削除ボタンだけはアコーディオン右端へ戻した。
- アコーディオン開閉ボタンを右端へ移し、表示を「+ / -」に変更した。
- アコーディオンは `.fb-field-header` 全体のクリックで開閉できるようにした。
- アコーディオンの「+ / -」表示を削除し、ヘッダークリックでの開閉だけを残した。
- 項目設定の本文を「基本設定」「入力設定」「表示設定」でグルーピングし、`fb-row` 内ラベルの文字サイズを下げた。
- 項目設定の「ヘルプテキスト（任意）」を「備考」に変更し、入力UIを複数行テキストにした。
- 備考ラベルも他の項目ラベルに合わせて小さい文字サイズに揃えた。
- フォーム編集見出しをパンくずに置き換え、現在地は基本設定のタイトル名を表示するようにした。スラッグ下の公開URLは外部リンク化し、`公開URL:` の文言を外した。
- `fb-field-section-title` の右側に区切り線を追加した。
- タブ文言を短縮し、項目見出しの「（フォームビルダー）」とアコーディオンサマリーの「項目」表記を削除した。
- 入力チェックの候補に「メールアドレス」を追加した。
- 入力チェックの候補に「電話番号」を追加した。
- ラジオボタンとプルダウンでは入力チェックを表示しないようにし、チェックボックスではカスタム正規表現のみ扱えるようにした。あわせて必須のチェックボックスに選択数設定（最小・最大）を追加し、入力チェック見出しの文言を削除した。
- チェックボックスの「選択数を設定する」を独立したチェック欄ではなく、入力チェックのプルダウン内の選択肢へ移動した。
- 基本設定のタイトル・説明文の表示チェックを各ラベル右側へ移動し、文言を「表示する」に変更した。
- タブ構成を「基本 / 入力画面 / 確認画面 / 完了画面 / 通知」に並べ替え、説明文を入力画面タブ上部へ、CAPTCHA 設定を入力画面タブ下部へ移動した。
- 通知タブ内の「本文テンプレート」表記を「表示設定」に変更し、確認画面・完了画面タブにも「表示設定」セクションを追加した。
- 入力画面・確認画面・完了画面タブ上部の見出しをいずれも「表示設定」に統一した。
- 入力画面の説明文入力を textarea から軽量 WYSIWYG エディタに変更し、公開側では許可した HTML を安全に表示できるようにした。
