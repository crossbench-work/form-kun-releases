# Changelog 2026-05-15

## フォーム編集

- フォーム編集の「基本」タブで、基本設定と並列の共通枠として `c-formBlock01` の `meta情報` ブロックを追加し、`c-inputSet01` で `metaタイトル` と `meta説明文` を設定できるようにした。
- `forms` テーブル / `SchemaPatch` / `Form` モデル / 管理画面コントローラを更新し、フォームごとに `meta_title` と `meta_description` を保存・検証できるようにした。
- 公開レイアウトはフォームの meta 設定を `<title>` / `<meta name="description">` に反映し、入力・確認・完了・各プレビューで画面タイトルを優先したタイトル文字列になるよう整理した。
- 上記の meta 設定は個別入力をやめ、`c-inputSet01` ひとつで head 用 HTML を直接書ける `meta情報（HTML）` 入力へ変更した。
- 新規フォームでは `description` / `og:*` を含むサンプルの meta HTML を初期値で表示し、既存の `meta_title` / `meta_description` が残っているデータは編集画面で互換変換して扱えるようにした。
- 基本タブ内の見出し文言を調整し、head 用 HTML ブロックのタイトルを `共通設定`、入力ラベルを `head` に変更した。
- head の初期サンプルは `description` と `keywords` を含む最小構成へ更新した。
- `共通設定` に head と並列の `css` / `js` 入力を追加し、フォームごとに公開フォーム専用の CSS / JavaScript を保存できるようにした。
- 公開レイアウトは保存した CSS を `<style>`、JavaScript を `<script>` として出力するようにした。
- `text_multi` の各入力欄の削除操作は `c-formEditor__actions` ではなく `m-deleteBtn01` の削除ボタンモジュールへ揃えた。
- `text_multi` の追加ボタンは `＋ 入力欄を追加する` から、説明文追加と同じ `m-btn01` / `m-formBuilder01__add` / `fb-description-add` 構成の `＋ 項目を追加` に揃えた。
- `text_multi` の追加ボタンは項目追加モーダルと干渉しない専用ターゲットへ戻し、文言も `＋ 文字を追加` に変更した。
- `c-formEditor__textMultiList` は `wrapper > .block.is-contents` を持つ構造へ変更し、各行は `.block.is-contents` の中で `.c-formEditor__field` と削除ボタンが横並びになるよう整理した。
- `text_multi` の各行は新しいモジュール構造に合わせて `area is-title` / `area is-field` に置き換え、ラベルも `表示` / `入力例` に変更し、各入力行のタイトルと入力欄が横並びになるよう調整した。
- `text_multi` の内側ラッパーは `c-formEditor__field` ではなく `c-formEditor__child__field` に変更し、指定どおりのマークアップと横並びレイアウトに合わせた。
- `c-formEditor__child__field > .wrapper` に flex を設定し、直下の `.block` 同士も横並びになるよう調整した。
- `c-formEditor__child__field` 内のラベル見出しは `m-labelTitle01` から `m-labelSmallTitle01` に変更した。
- `m-btn01` に追加ボタン用の `is-add` スタイルを追加し、`text_multi` の `＋ 文字を追加` ボタンでも利用するようにした。
- `c-formEditor__textMultiEditor` は廃止し、`data-text-multi-editor` を `c-formEditor__textMultiList` に寄せてラッパーを統合した。
- `text_multi` の追加ボタンと hidden textarea は `c-formEditor__textMultiList` 内の `block.is-contents` に移し、指定の入れ子構造に合わせた。
- `text_multi` の追加ボタンと hidden textarea は最後の `c-formEditor__textMultiItem > .wrapper` 内へ移し、JS でも末尾の項目に追従するように調整した。
- `text_multi` の追加ボタン文言は `＋ 文字を追加` から `＋ 入力エリアを追加` に変更した。
- `m-btn01` に `data-position="center"` を追加できるようにし、`text_multi` の追加ボタンを中央寄せで表示するようにした。
- フォーム項目エディタ内の `c-formEditor__field` 系行は、`block is-title / is-field` ではなく `area is-title / is-field` の横並び構造へそろえ、hidden template と `checkboxLimit` を含む同系統のマークアップも合わせて更新した。
- `入力チェック` の必須トグルは見出し右へ移し、文言も `必須` から `必須にする` に変更した。
- `text_multi` の一覧は `block.is-contents` 配下を `area is-contents` 単位に整理し、各入力エリアと追加ボタンを同じ階層で並べる構造へ変更した。
- `文字数制限（任意）` の最小・最大入力は inline style をやめ、`c-formEditor__child__field` を使う構造へ置き換えた。
- `text_multi` の `m-labelSmallTitle01` ラベルは `class="label"` を外し、`<label data-module="m-labelSmallTitle01">` の形へそろえた。
- `文字数制限（任意）` の `c-formEditor__child__field` には `最小` / `最大` の小見出しを追加した。
- `.c-formEditor__child__field` 内の `.area.is-title` は折り返さないように調整した。
- hidden template の `入力チェック` ブロックで閉じタグが崩れていたため、追加直後の `必須` と `文字数制限` の横並びが壊れる不具合を修正した。
- 説明文入力は `c-formEditor__field > .wrapper > .block.is-contents > .area.is-title / .area.is-field` 構造へ変更し、hidden template も同じマークアップにそろえた。
- 選択肢エディタは `text_multi` と同じ階層構造へ寄せ、`c-formEditor__field` / `c-formEditor__child__field` / `area.is-contents` ベースのマークアップと追加・並び替え処理へ更新した。
- 選択肢エディタの操作は上下ボタンをやめ、左側ドラッグハンドルで並び替える方式に変更し、削除ボタンも `m-deleteBtn01` に統一した。
