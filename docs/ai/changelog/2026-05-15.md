# Changelog 2026-05-15

## フォーム編集

- フォーム編集の「基本」タブで、基本設定と並列の共通枠として `c-formBlock01` の `meta情報` ブロックを追加し、`c-inputSet01` で `metaタイトル` と `meta説明文` を設定できるようにした。
- `forms` テーブル / `SchemaPatch` / `Form` モデル / 管理画面コントローラを更新し、フォームごとに `meta_title` と `meta_description` を保存・検証できるようにした。
- 公開レイアウトはフォームの meta 設定を `<title>` / `<meta name="description">` に反映し、入力・確認・完了・各プレビューで画面タイトルを優先したタイトル文字列になるよう整理した。
- 上記の meta 設定は個別入力をやめ、`c-inputSet01` ひとつで head 用 HTML を直接書ける `meta情報（HTML）` 入力へ変更した。
- 新規フォームでは `description` / `og:*` を含むサンプルの meta HTML を初期値で表示し、既存の `meta_title` / `meta_description` が残っているデータは編集画面で互換変換して扱えるようにした。
- 基本タブ内の見出し文言を調整し、head 用 HTML ブロックのタイトルを `共通設定`、入力ラベルを `head` に変更した。
- head の初期サンプルは `description` と `keywords` を含む最小構成へ更新した。
