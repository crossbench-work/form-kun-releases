# Changelog 2026-05-12

## スタイル・マークアップ

- 公開／管理 UI を html-markup スキル（`l-` / `p-` / `m-` / `data-module` 等）に沿う形へ整理。
- SCSS エントリ（`_s_reset` / `_s_config`）と `npm run build:css` による CSS ビルドを導入。
- 説明文追加 UI の先頭プルダウンを削除し、各説明文ブロックの挿入位置は「先頭 / 末尾」のみ選べるように整理した。
- 説明文ブロックの挿入位置セレクトからラベルを外し、表示チェックを右横へ寄せた。あわせて説明文追加ボタンを一覧の下へ移動し、見出し表記を簡潔化した。
- 説明文ブロックで「末尾」を選んだ場合は、公開フォームの `.p-formInput01` の外側下部へ表示するように変更した。
- 確認画面と完了画面にも説明文ブロックの挿入設定を追加し、管理画面では入力画面と同じ操作感で複数の説明文を配置できるようにした。
