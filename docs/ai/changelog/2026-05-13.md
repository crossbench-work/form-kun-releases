# Changelog 2026-05-13

## スタイル・マークアップ

- 管理画面で使っていたパネル用クラス `.m-panel01` を `.c-panel01` へ変更し、対応するテンプレートと SCSS/CSS の命名をそろえた。
- 管理画面パネルのマークアップに `.componentWrapper` を追加し、共通ラッパー前提のスタイル指定へ合わせた。
- `.componentWrapper` は `c-panel01` と同じ要素へ併記せず、直下の子要素として 1 階層内側に置く形へ修正した。あわせて HTML マークアップ規約にも配置ルールを追記した。
- 管理画面パネルは `m-panel01 > .wrapper` を正とする形へ戻し、テンプレート・SCSS/CSS・HTML マークアップ規約をその構造に合わせて更新した。
- 管理画面パネルはさらに `.wrapper > .block` を必須にする形へ整理し、`m-panel01 > .wrapper > .block` を正としてテンプレート・SCSS/CSS・HTML マークアップ規約を揃えた。
- 管理画面パネルのルートは `.m-panel01` ではなく `<div data-module="c-panel01">` を正とし、テンプレート・SCSS/CSS・HTML マークアップ規約を `[data-module="c-panel01"] > .wrapper > .block` 前提へ更新した。
- 管理画面パネル内のコンテンツブロックは `<div class="block is-contents">` を正とし、テンプレート・SCSS/CSS・HTML マークアップ規約を `[data-module="c-panel01"] > .wrapper > .block.is-contents` 前提へ更新した。
- 管理画面パネルの設定 DOM は外枠 `c-panel01` の内側に `c-formBlock01 > .wrapper > .block.is-contents` を入れる構造へ整理し、テンプレート・SCSS/CSS・HTML マークアップ規約を揃えた。
- フォーム編集画面の説明文エディタにあった余分な閉じタグを削除し、`c-panel01` が `l-adminBody01 > .wrapper` の内側から外れないように構造を修正した。
- 管理画面の大見出しスタイルは `.l-adminShell01 h2` の要素指定をやめ、`data-module="m-largeTitle01"` を付けた見出しだけへ当たるように変更した。
- 管理画面の `input` / `select` / `textarea` は `data-module="m-inout01"` を付ける形へ揃え、入力スタイルを `m-authForm01` / `c-formBlock01` から `m-inout01` モジュールへ切り出した。
- `c-formBlock01 > .wrapper > .block.is-contents` の直下 DOM は `area is-title` / `area is-field` に整理し、見出しと各入力・表示ブロックを同じ構造でまとめるように更新した。
- 管理画面の入力モジュールは要素直付けではなく `<div data-module="m-input01">` で包む構造へ変更し、テンプレート・SCSS/CSS・HTML マークアップ規約を wrapper 前提へ更新した。
- フォーム編集画面の説明文エディタは `area is-field` 直下の単一 DOM ではなく、`<div data-module="c-descriptionEditor01"><div class="wrapper"><div class="block is-contents">...</div><div class="block is-toolbar">...</div></div></div>` の構造へ変更した。
- `c-descriptionEditor01` の内部でも `fb-description-blocks` などの独自ラッパーを減らし、`area is-blocks` / `area is-block` / `box is-header` / `box is-controls` などコンポーネント規約に沿った DOM へ整理した。
- `c-descriptionEditor01` の説明文一覧ラッパーは `area is-blocks` ではなく `.c-descriptionEditor01__editor` に変更し、コンポーネント専用のラッパー名として扱うように整理した。

- `.c-descriptionEditor01__editor` の各説明文ブロック内は `box is-header` などをやめて `area is-header` / `area is-controls` / `area is-editor` / `area is-help` へ変更し、階層を増やしすぎない構造へ整理した。
- `.c-descriptionEditor01__editor` は `wrapper > .block.is-contents` を直接並べる構造へ見直し、説明文一覧の管理用属性は `wrapper` に寄せて余分な `block.is-list` / `area.is-block` をなくした。
